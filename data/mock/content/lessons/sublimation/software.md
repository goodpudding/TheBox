# Sawgrass Print Manager

The shop computer prints through **Sawgrass Print Manager / Print Utility**. Use the substrate preset that matches what you are pressing. Mirroring, colour profile, and quality live in that utility — not in a random “print to USB” path.

Watch the assigned video for the click-path. If colour looks wrong, check: preset, paper print-side, and that you mirrored — before blaming the printer.
